# playground

收集好玩的 GitHub 项目：iOS 侧载、模拟器、小工具。

> 提醒：免费证书签的 App 7 天过期要续；改过的 App 别登太重要的账号；越狱插件需要 iOS 16 及以下，iPhone 17（iOS 27）装不了。

## 先装商店

- [AltLoad](https://github.com/mirazbakis/AltLoad) — iOS 27 上不用电脑就能装 AltStore / SideStore，用自己的 Apple ID 签名
- [AltStore](https://github.com/altstoreio/AltStore) — 老牌侧载商店，要配电脑上的 AltServer 续签
- [SideStore](https://github.com/SideStore/SideStore) — AltStore 的分支，装好后不用电脑也能续签
- [LiveContainer](https://github.com/LiveContainer/LiveContainer) — 免费证书只有 3 个 App 位子，它能让你一个位子跑多个 App

## 模拟器

- [Delta](https://github.com/rileytestut/Delta) — 任天堂模拟器，NES、SNES、N64、GBA、NDS 都能玩
- DolphiniOS — NGC / Wii 模拟器，在下面的源里能找到

## 改版 App

- [uYouEnhanced](https://github.com/arichornlover/uYouEnhanced) — 无广告 YouTube + 后台播放，功能最全
- [YTLitePlus](https://github.com/YTLitePlus/YTLitePlus) — 同上，轻量稳定，不发热
- SpotX — 去广告版 Spotify

## 一个现成的源，一次加 25 个

把 `https://kb01111.github.io/Sideload-Sources/source.json` 粘贴到 SideStore / AltStore 的 Sources 里，里面全是开源 App，一键装。

- [KB01111/Sideload-Sources](https://github.com/KB01111/Sideload-Sources)

## 小组件和其他

- Scriptable — App Store 下，GitHub 上搜 Scriptable widget，一堆现成小组件脚本
- [CleanYourTV](https://github.com/Gathin23/cleanyourtv) — 电视去臃肿
- [freebie-radar](https://github.com/8P6E9K3/freebie-radar) — 薅羊毛雷达
